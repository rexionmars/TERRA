% COLUNA ALINHADA A ESQUERDA, herdada do guia geral com a mesma medida e a
% mesma razao. As tabelas deste livro tem colunas estreitas, e `p{}` justifica:
% a essa largura o justificado abre buracos entre palavras. O `plus 2em` em vez
% do `plus 1fil` do \raggedright preserva o diagnostico: com folga infinita a
% direita, TeX nunca acha uma linha larga demais, e uma celula com um caminho
% de arquivo em monoespacada -- que nao hifeniza -- vaza por cima da coluna
% vizinha sem uma linha de `Overfull` no log.
\newcolumntype{L}[1]{>{\raggedright\arraybackslash\rightskip=0pt plus 2em\relax\hbadness=10000\relax}p{#1}}
